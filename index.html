C01 Explain the operation of functional units of a typical computer architecture w.r.t instruction execution, control signal generation

This course outcome is mapped to cognitive level 2 because it involves comprehending the roles of functional units of computer and their coordination in executing instructions and generating control signals. Internal Exam
C02 Explain the architecture of 8051 microcontroller and develop simple programs using assembly language programming.

This course outcome is mapped to cognitive level 2 because it emphasizes understanding the 8051 architecture and applying foundational knowledge to create simple assembly language programs. Internal Exam
C03 Develop ALP/Embedded C programs to interface 8051 microcontroller with various peripheral devices

This course outcome is mapped to cognitive level 3 because it requires students to apply their programming skills and knowledge of interfacing techniques to implement functional systems using the 8051 microcontroller. Internal Exam, Course Project interim and final evaluation, Course Project report

This course outcome is mapped to cognitive level 2 because it focuses on grasping the foundational principles of embedded C programming and their application to solve basic embedded system tasks. Internal Exam
